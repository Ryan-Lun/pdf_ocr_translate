# Selected Department Glossary is explicit and singular

User-facing translation job submissions must explicitly choose one Selected Department Glossary, and that job must keep using the same selected glossary for worker processing and editor retranslation. We chose this over defaulting silently or merging multiple department glossaries because glossary terms are authoritative lexical rules: requiring an explicit single choice prevents accidental cross-department terminology mixing while keeping Required Glossary Term validation, Translation Memory priority, and job traceability explainable.
