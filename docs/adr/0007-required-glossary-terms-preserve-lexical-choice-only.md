# Required Glossary Terms Preserve Lexical Choice Only

Glossary terminology is split between Exact Protected Content, which remains fully immutable, and Required Glossary Terms, which must use the approved target-language term exactly while allowing the model to reposition the term and rewrite surrounding syntax naturally. We chose this over fully opaque glossary tokens because opaque tokens preserve terminology reliably but can also freeze source-language word order and create literal target-language phrasing.
